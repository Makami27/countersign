    How it decides

    Said isn't proven

    Every address in memory is marked verified or stated. Messages, emails and invoices can only ever add a stated address, and stated addresses can't be paid.

    The old wallet signs for the new one

    A change goes through only when the payee's current wallet signs it, or you confirm it and a waiting period passes. The new wallet must prove it's in control too. Anyone can prove control of their own wallet, so that alone is never enough.

    Memory that can't be forged

    Records live in Walrus Memory and are signed by the agent. Text shaped like a record is ignored. If memory can't be read completely, or the chain doesn't answer, nothing is paid.
