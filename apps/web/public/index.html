Your agent only pays signatures it has on file.

Countersign pays your regular payees in USDC on Sui. Like a bank comparing a cheque with the signature card, it checks every request against the wallet that signed for that payee, and refuses the rest.

How it works

  1. A payee signs once

    When you add a payee, their own wallet signs a message proving the address is theirs. That signature goes on the card. Until then, the agent can't pay them.

  2. Messages can only suggest

    Emails, chats and invoices can name an address, but they only ever add one marked Stated. Stated addresses are never paid, however convincing the letter.

  3. A change needs the old wallet's signature

    To move a payee to a new wallet, the wallet on file signs for it, or you confirm it and a waiting period passes. Proving control of the new wallet alone is never enough.
